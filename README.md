# FrontEnd Store

Mi segundo proyecto web. Una tienda de una página en HTML y CSS, sin
frameworks ni librerías.

**En línea:** https://2doprojectweb-fron-store-gibson1987r.netlify.app

## Qué es

Un ejercicio de un curso de CSS: catálogo de productos en rejilla, cabecera con
navegación, secciones de contenido y diseño adaptable al móvil.

El diseño y las imágenes son del curso; lo mío es la maquetación. Lo subo tal
cual, sin retocarlo. Es de diciembre de 2022.

## Cómo verlo

No hace falta compilar nada. Abre `index.html` en el navegador.

## Estructura

```
index.html          La página entera
css/normalize.css   Reset de estilos entre navegadores
css/style.css       Los estilos del proyecto
img/                Fotos del catálogo y el logo
```
